## 🏛️ About This Casebook

This repository reimagines a standard Python bridge-course lab notebook as a **courtroom casebook** — ten laboratory experiments, tried as ten trials, with every recurring section of every exercise rewritten in legal vocabulary instead of the usual "Goal / Concept / Explanation" format.

| Standard Lab Format | → | This Casebook |
|---|---|---|
| Question | → | ⚖️ Case File |
| Goal | → | Objective of the Trial |
| Concept | → | Statute & Precedent |
| Flowchart | → | Case Diagram |
| Code | → | 📁 Exhibit A — The Evidence |
| Output | → | Court Record |
| Explanation | → | 🎙️ Cross-Examination |
| Real-World Use | → | 🏛️ Precedent for Future Cases |
| Common Mistakes | → | 🚫 Grounds for Mistrial |
| Summary | → | 🔨 The Verdict |

Every one of the **77 case files** across the 10 trials follows this same structure end to end — same court, same procedure, ten different charges.

## 📖 Docket of Trials

| Trial | Case Title | Topics Covered |
|:-----:|:-----------|:----------------|
| 01 | *The People vs. The Blank Terminal* | Python installation, Interactive vs. Script Mode, `print()` |
| 02 | *The Case of the Miscalculated Ledger* | Operators, input/output, expressions |
| 03 | *State vs. Ambiguity* | Conditional statements — `if` / `elif` / `else` |
| 04 | *The Repeat Offender Docket* | Loops — `for`, `while`, nested loops |
| 05 | *Testimony Under the Microscope* | Strings and sets |
| 06 | *The Evidence Locker* | Lists, tuples, and dictionaries |
| 07 | *Delegation of Duty* | Functions, parameters, recursion |
| 08 | *Objection, Your Honor!* | File handling and exception handling |
| 09 | *Establishing Legal Identity* | Classes, objects, and inheritance |
| 10 | *The Closing Argument* | NumPy, Pandas, and Matplotlib |

Every trial opens with an **Opening Statement**, lists the **Charges to Be Proven** (learning objectives), and cites the **Statutes** (topics) tried in that session.

## ⚙️ How to Run

```bash
# Clone the repository
git clone <your-repo-url>
cd <your-repo-folder>

# Install dependencies
pip install numpy pandas matplotlib

# Launch the notebook
jupyter notebook "courtroom_notebook.ipynb"
```

The notebook runs top to bottom like any standard lab notebook — the courtroom framing is presentation only; every code cell is untouched, standard, runnable Python.
